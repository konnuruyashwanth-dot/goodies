DEPLOYING TO VERCEL (the reliable way)
======================================

Why the video "wouldn't update": Vercel deploys whatever was pushed to your
Git repo / uploaded — NOT the zip, and NOT your local folder automatically.
So earlier edits never reached the live site. The command below uploads the
ACTUAL current files every time, so what you see locally is what goes live.

ONE-TIME SETUP
--------------
1. Install Node.js if you don't have it: https://nodejs.org  (LTS version)
2. Open Terminal and run:   npm i -g vercel

DEPLOY (run these 2 lines whenever you want to publish/update)
--------------------------------------------------------------
    cd "<path to>/cat-little-box"
    vercel --prod

- First run: it asks a few questions — accept the defaults.
  * Set up and deploy? Yes
  * Which scope? (your account)
  * Link to existing project? No (first time) / Yes (after)
  * Project name? cat-little-box   (or anything)
  * In which directory is your code? ./       <-- IMPORTANT: just "./" (you are
    already inside cat-little-box, so index.html is right here)
  * Framework preset? Other
  * Build/Output/Install commands? leave all empty
- It prints a live URL. That's your link.
- To UPDATE later: edit files, run `vercel --prod` again. Done.

IF YOU USED THE VERCEL WEBSITE + GITHUB INSTEAD
-----------------------------------------------
- Root Directory must be set to the folder that contains index.html
  (select "cat-little-box"), Framework = Other, no build command.
- You must COMMIT & PUSH your changes to GitHub for the site to update.
  If the video looks old, your latest files aren't pushed yet.

AFTER DEPLOY
------------
- Test in an incognito/private window so you're not seeing a cached version.
- The very first video play on a fresh deploy can buffer for a second while
  the CDN caches it; after that it's instant.

STILL CHOPPY?
-------------
Static hosts aren't built for video streaming. The bulletproof fix is to put
the video on YouTube/Vimeo (can be unlisted/private) and embed it. Ask and I'll
switch the video card to an embed.
